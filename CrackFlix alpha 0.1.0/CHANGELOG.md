# Changelog

All notable changes to CrackFlix are documented in this file.

## [0.1.0-alpha] — Initial Release

### Added

* Initial CrackFlix theme for Jellyfin
* Netflix-inspired dark interface
* CrackFlix red accent color system
* Customized Jellyfin navigation and header
* Customized buttons and interactive elements
* Customized media cards and poster hover effects
* Customized progress bars and sliders
* Customized dialogs, popups and controls
* Customized login interface
* Responsive Hero banner
* Dynamic Hero banner with randomly selected movies and series
* Hero title, description and content type indicator
* Hero **PLAY** and **MORE INFO** actions
* Custom video player episode button and visual episode panel
* Cross-platform styling and functionality

### Fixed

* Prevented the Dynamic Hero from appearing inside the Jellyfin Favorites view
* Added protection against duplicate Hero banners during Jellyfin page updates
* Improved Hero targeting when Jellyfin dynamically re-renders page content

### Tested

CrackFlix 0.1.0-alpha has been tested on:

* PC Web Browser
* Jellyfin Media Player
* Mobile Web Browser
* Jellyfin Mobile App
* Xbox One
* Xbox Series S

### Notes

CrackFlix 0.1.0-alpha is the first public release.

The visual appearance may differ between Jellyfin clients because each client can use different rendering systems and UI components.

The Jellyfin Web interface is the primary visual design reference for this release.
